# Architecture Decision Records

Index of locked architectural decisions for kultivait. Each ADR captures the context, options considered, and consequences of an architectural choice. ADR prose is immutable; decisions are amended or extended by subsequent ADRs rather than rewritten in place.

| ADR | Title | Gist |
|---|---|---|
| [0001](0001-trolltoll-holds-requests.md) | Trolltoll holds requests open | Holds caller HTTP requests open up to `toll_timeout_s` (60s) during contested routing decisions to let a human choose the path. |
| [0002](0002-orchestration-fit-at-boundaries.md) | Orchestration fits at boundaries | Leaves client agent loops intact and fits model tier and effort dynamically at request and sub-task boundaries. |
| [0003](0003-route-menu-and-frontier-targets.md) | Route menu presents ranked installed targets with auto-policy local default | Presents top installed frontier targets ranked by fit with fitted effort when routing is contested, defaulting to local on expiry. |
| [0004](0004-api-frontier-surface.md) | API frontier: three standalone provider backends, manual registration, pinned model ids | Integrates Anthropic, OpenAI, and OpenRouter direct pay-per-token backends via manual config registration and pinned model IDs. *(Historical drift: classes now live in `src/kultivait/api_backends.py`, not `backends.py`; shipped curated defaults are `claude-3-7-sonnet-20250219` and `gpt-4o` rather than provisional pre-release names; original prose kept untouched).* |
| [0005](0005-cost-model-duality.md) | Cost model duality: metered cash and notional value tracked as separate lenses | Separates real metered cash billed by API providers from notional replacement value of local dispatches, extended with cache economics. |
| [0006](0006-mixed-route-menu.md) | Mixed route menu: capability filter over one grown candidate pool, local-first auto-policy | Unifies CLI and API targets into a single route menu pool with tool-capability filtering and local-first fallback. |
| [0007](0007-preprocessor-tool-treatment.md) | Preprocessor treatment of tool-bearing requests: unconditional on contested, unchanged surface | Evaluates preprocessor verdicts unconditionally on contested requests while suppressing sub-task decomposition when tools are present. |
| [0008](0008-api-effort-projection.md) | API effort projection: canonical currency, backends self-project, per-model token tables | Standardizes canonical effort (fast/balanced/deep) across providers, letting backends self-project to provider-specific reasoning flags. |
| [0009](0009-benchmark-harness-shape.md) | Benchmark harness redefined as a direct-to-backend capability eval | Evaluates tool-bearing capability directly against backends with model-as-judge scoring rather than synthetic routing replay. |
| [0010](0010-key-management-and-onboarding.md) | Key management: env → keychain → credentials file, presence probe at menu build | Resolves provider API keys via a strict three-tier hierarchy (`env` → macOS keychain → `~/.kultivait/credentials.toml` `0600`) without CLI key-entry commands. |
| [0011](0011-api-retry-and-failover.md) | API retry & failover: aggressive buffered retry, fail-fast headless, unbounded failover | Implements buffered response replay with up to 5 jittered retries on transient API errors, failing fast for headless calls and offering failover on human toll choices. |
| [0012](0012-distillation-targets.md) | Distillation targets: the whole preprocessor contract on one model, toll-rate headline | Targets distilling the entire preprocessor contract (judge, analyzer, rewriter) into a single local fine-tuned model to compress routing latency. |
| [0013](0013-corpus-and-label-assembly.md) | Corpus & label assembly: serving-shape pairs, tiered truth, teacher rewrites | Structures distillation datasets as serving-shape chat JSONL with a truth hierarchy (gold human tolls, silver execution outcomes, bronze eval scores). |
| [0014](0014-training-method-and-hardware-budget.md) | Training method: mlx-lm QLoRA on both bases, capped envelope with an escalation ladder | Fine-tunes 4-bit QLoRA models on Apple Silicon via `mlx-lm` enforcing a strict memory ladder that aborts rather than swap. |
| [0015](0015-distillation-eval-protocol.md) | Distillation eval protocol: five gates with a powered headline, two-sided band discipline | Validates candidate distillates against a permanent held-out set across five quantitative gates (safety, parse validity, latency, agreement, band discipline). |
| [0016](0016-teacher-selection-and-synthetic-policy.md) | Teacher & synthetic policy: neutral judge teacher + claude rewriter, agreement-filtered | Employs dual-teacher synthetic data generation with agreement filtering across balanced strata (amended to neutral API judge + local variation drafting). |
| [0017](0017-distillate-deployment-and-shadow-rollout.md) | Distillate deployment & shadow rollout: [distill] config seat, post-response shadow | Serves distillates via a configurable `[distill]` seat with asynchronous post-response shadow evaluation and human-confirmed cutover. |
| [0018](0018-cache-breakpoints.md) | Cache breakpoints: proxy-owned at the stable prefix, Anthropic-form canonical, 5m default | Manages prompt cache breakpoints deterministically at tools and system prompt boundaries for prefixes over 1,024 tokens with 5m default TTL. |
