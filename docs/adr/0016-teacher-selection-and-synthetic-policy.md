# Teacher & synthetic policy: neutral judge teacher + claude rewriter, agreement-filtered Gate-clone pipeline, contested-heavy strata, 3-stage personal-use filtering

Teachers are **two named roles on installed CLI channels** (subscription-covered, $0 metered — no API keys are registered on this machine; teachers dogfood kultivait's own CLI backends): the **judge teacher** labels synthetic prompts' verdict **tier** — the judgmental act under #46's cross-family rule — and must be a family with **no fitted route target**: **GLM via the opencode CLI** (fitted families today are anthropic=claude, openai=codex, google=gemini/agy; GLM has no dog in the fight); the **rewriter teacher** is unconstrained per #46 and goes to **the claude CLI** (the herd's highest-capability writer). Teachers never emit fit numbers — fits stay regressed from tier labels by the corpus builder. The generation pipeline is a **Gate-clone corpus generator** (the gates.py template-driven, generate-function-injected pattern): seeded by anchor-set prompts + escalation archives + a target band and task_type, step 1 the judge teacher generates band-targeted variations; step 2 it independently labels each variation's tier in a second pass, and only pairs where **intended band == labeled band survive** (the agreement filter — the generator cannot smuggle mislabeled cases into the corpus); step 3 the rewriter teacher writes the rewrite given prompt + tier; step 4 the corpus builder synthesizes fits/confidence from the confirmed tier (band placement + spread) and emits the serving-shape pair. Deterministic seeds; fully re-runnable. Strata are **deliberately contested-heavy: 40% contested / 30% local-clear / 30% frontier-clear** (the contested band is the behavior being fixed and real anchors almost never produce contested cases; clear bands keep bulk behavior grounded), cross-cut by task_type (each contract enum value ≥ 10% of corpus) with roughly uniform complexity within band; every pair carries its stratum as metadata so the eval slices per stratum and the augment rung grows exactly the failing stratum (+500 targeted). Quality is a **three-stage filter**: **dedup** (exact normalized-hash, then near-dup via the existing embedding model at cosine > 0.92 dropped), **schema** (contract JSON parses, fields typed, tier-consistent fits — local-clear < 0.65, contested in-band, frontier ≥ 0.85 — monotone target ordering), **quality** (rewrites preserve the prompt's load-bearing facts via a planted-fact check reusing evals.py's recall scoring, plus the tier-agreement pass). The ToS position is **pragmatic personal-use**: teacher outputs enter the corpus via subscription CLIs for personal dogfooding; every pair carries provenance (teacher family, channel, seed source); **the corpus is never redistributed or published**; the interpretation that a routing judge is not a "competing model" under frontier terms is recorded here for re-review if the corpus ever leaves this machine.

## Considered Options

- **Single teacher (claude) for both roles**: rejected — claude's family is a fitted target; tier labels would carry self-promotion bias, violating #46's extended rule.
- **Paired exclusion teachers** (claude labels non-anthropic-leaning, codex non-openai, merge): rejected — two judges introduce between-half label-scale drift exactly where eval consistency matters.
- **Rotating teachers across corpus chunks**: rejected — averages bias but injects between-chunk variance; one neutral judge is cleaner.
- **Free-form generation with post-filtering**: rejected — label quality becomes whatever the generator felt like; band targeting degrades to luck.
- **Hand-written templates + teacher labels only**: rejected — diversity collapses to the template author's imagination; overfits.
- **Traffic-matched strata** (~88/8/4): rejected — trains almost no contested examples; the flywheel's target behavior stays starved.
- **Uniform thirds**: rejected — underserves clear-band grounding that daily traffic actually is.
- **Schema-only filtering**: rejected — lets near-duplicate floods and fact-dropping rewrites through to training.
- **Strict no-train ToS reading**: rejected — kills the pipeline v1 (no labels exist without teachers); the personal-use scope with provenance and no-redistribution is the documented, reviewable position.

## Consequences

- The corpus generator is a read-side consumer of the harvest (anchor set + escalations) and a write-side producer of `train.jsonl` + stratum metadata; no ledger schema change.
- Teacher dispatch rides existing CLI backends — the presence probe and tollbooth treat teacher traffic like any other; teacher runs are ledger-tagged (subscription, $0 metered) so corpus cost is visible in the harvest's notional lens.
- The agreement filter's two-pass discipline means generation cost is ~2 judge calls + 1 rewriter call per surviving pair (~1–2k pairs → ~4–6k CLI dispatches per corpus build, on-subscription).
- Stratum metadata feeds #49's per-stratum eval slices and the augment rung's targeting; dataset versioning inherits provenance + strata as first-class fields.
- If a GLM-family target ever enters the route menu, the judge teacher's neutrality breaks — the ADR's rule requires re-selecting the judge teacher at that point.
- Term canonized in CONTEXT.md: **Agreement filter**.
